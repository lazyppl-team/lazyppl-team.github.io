<p>We have six people, and we know that some of them talk to each other, and some of them don’t talk to each other. We want to infer the social groups. This is <span class="prose-compound">non-parametric</span> in that we don’t assume a fixed number of social groups.</p>
<p>We set up a data type inhabited by the people of interest.</p>

<h2 id="the-model">The model</h2>
<p>The model is set up by building a Chinese Restaurant and placing the people at tables in it. Here we are using our Chinese Restaurant process interface (<code>Distr.DirichletP</code>). It involves abstract types <code class="sourceCode haskell"><span class="dt">Restaurant</span></code> and <code class="sourceCode haskell"><span class="dt">Table</span></code>, and provides two functions:</p>
<ul>
<li><code class="sourceCode haskell"><span class="ot">newRestaurant ::</span> <span class="dt">Double</span> <span class="ot">-&gt;</span> <span class="dt">Prob</span> <span class="dt">Restaurant</span></code>, which provides a new restaurant;</li>
<li><code class="sourceCode haskell"><span class="ot">newCustomer ::</span> <span class="dt">Restaurant</span> <span class="ot">-&gt;</span> <span class="dt">Prob</span> <span class="dt">Table</span></code>, which says which table a new customer will sit at.</li>
</ul>
<p>The model describes an unnormalized probability measure on functions assigning tables to people.</p>

<h2 id="running-the-model">Running the model</h2>
<p>We sample from this unnormalized measure using a <span class="prose-compound">Metropolis-Hastings</span> simulation. We calculate the probability of Tom/Fred and Tom/Mary sitting together, and also plot a graph of the sample with the highest likelihood.</p>
