4c:Tba22,<span id="top"></span><p>One advantage of probabilistic programming in a general purpose
language is that we can import existing libraries as part of our models.
Here we follow an example from the Anglican team with a simple 2d
physics problem based on the Chipmunk library. For the Anglican example
see the <a href="https://bitbucket.org/probprog/mlss2015/src/master/">Machine
Learning Summer School</a> or <a href="https://github.com/hongseok-yang/probprog19/blob/master/Lectures/Lecture4/PhysicsLec4.clj">the
KAIST lecture course</a>. For more advanced physics simulations in
probabilistic programming, see <a href="https://iris-hep.org/projects/ppx.html">PPX</a>.</p>
<p>Thanks also to <a href="https://github.com/ahuoguo/lazyppl_physics">Alexander Bai</a> for
initially adapting the Haskell implementation in Sam’s <a href="https://www.cs.uoregon.edu/research/summerschool/summer19/topics.php#Staton">OPLSS
course</a> to LazyPPL.</p>
<p>The source for this Literate Haskell file is currently <a href="https://github.com/lazyppl-team/lazyppl_physics">here</a>.</p>

<li><p>We want to place and orient bumpers so that the ball falls in to
the cup.</p></li>

<h2 id="the-lazyppl-model">The LazyPPL model</h2>
<p>The model:</p>
<ul>
<li><p>Pick some bumper positions and angles uniformly</p></li>
<li><p>Run the 2d physics</p></li>
<li><p>Then observe that the ball lands <span class="prose-compound">more-or-less</span> in the
cup.</p></li>
<li><p>Return a posterior distribution over bumper positions and
angles.</p></li>
</ul>
<div class="sourceCode code-block" id="cb9"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb9-1"><a href="#cb9-1" aria-hidden="true" tabindex="-1"></a><span class="ot">model ::</span> <span class="dt">Meas</span> [(<span class="dt">Double</span>,<span class="dt">Double</span>,<span class="dt">Double</span>)]</span>
<span id="cb9-2"><a href="#cb9-2" aria-hidden="true" tabindex="-1"></a>model <span class="ot">=</span> <span class="kw">do</span></span>
<span id="cb9-3"><a href="#cb9-3" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- Pick the positions and angles of two bumpers</span></span>
<span id="cb9-4"><a href="#cb9-4" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- Prior is uninformative, uniformly distributed</span></span>
<span id="cb9-5"><a href="#cb9-5" aria-hidden="true" tabindex="-1"></a>  bumpers <span class="ot">&lt;-</span> sample <span class="op">$</span> replicateM <span class="dv">2</span> <span class="op">$</span> <span class="kw">do</span></span>
<span id="cb9-6"><a href="#cb9-6" aria-hidden="true" tabindex="-1"></a>                      x <span class="ot">&lt;-</span> uniformbounded (<span class="op">-</span><span class="dv">5</span>) <span class="dv">5</span></span>
<span id="cb9-7"><a href="#cb9-7" aria-hidden="true" tabindex="-1"></a>                      y <span class="ot">&lt;-</span> uniformbounded (<span class="op">-</span><span class="dv">5</span>) <span class="dv">5</span></span>
<span id="cb9-8"><a href="#cb9-8" aria-hidden="true" tabindex="-1"></a>                      theta <span class="ot">&lt;-</span> uniformbounded <span class="dv">0</span> <span class="fu">pi</span></span>
<span id="cb9-9"><a href="#cb9-9" aria-hidden="true" tabindex="-1"></a>                      <span class="fu">return</span> (x,y,theta)</span>
<span id="cb9-10"><a href="#cb9-10" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- Run the physics simulation.</span></span>
<span id="cb9-11"><a href="#cb9-11" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- The last point is where the ball either leaves the scene</span></span>
<span id="cb9-12"><a href="#cb9-12" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- or lands in the cup. </span></span>
<span id="cb9-13"><a href="#cb9-13" aria-hidden="true" tabindex="-1"></a>  <span class="kw">let</span> (x,y) <span class="ot">=</span> unsafePerformIO <span class="op">$</span></span>
<span id="cb9-14"><a href="#cb9-14" aria-hidden="true" tabindex="-1"></a>              <span class="kw">do</span> { pos <span class="ot">&lt;-</span> getTrajectory bumpers ; <span class="fu">return</span> <span class="op">$</span> <span class="fu">last</span> pos }</span>
<span id="cb9-15"><a href="#cb9-15" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- Observe the ball is roughly in the cup at the end of the trajectory</span></span>
<span id="cb9-16"><a href="#cb9-16" aria-hidden="true" tabindex="-1"></a>  score <span class="op">$</span> normalPdf <span class="fl">4.5</span> <span class="fl">0.2</span> x </span>
<span id="cb9-17"><a href="#cb9-17" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- Return the bumper positions</span></span>
<span id="cb9-18"><a href="#cb9-18" aria-hidden="true" tabindex="-1"></a>  <span class="fu">return</span> bumpers</span></code></pre></div>
<p>Note that we do not say that the ball lands exactly in the cup. We
could consider an alternative model by replacing the score with
<code>score $ fromEnum (x &gt; 4 &amp;&amp; x &lt; 5)</code>. This would
lead to <span class="prose-compound">Metropolis-Hastings</span> rejecting the first samples, finding the
first success by <a href="#brute-force">brute force</a>, which takes a
lot longer.</p>

<p>The four simulations at the <a href="#top">top of the page</a> were
found by <span class="prose-compound">Metropolis-Hastings</span> simulation.</p>
<p>Running the model with the LazyPPL <span class="prose-compound">Metropolis-Hastings</span> gives
trajectories like this (this is 1000 samples; the very last sample is
the <span class="prose-compound">bottom-right</span> animation at the top of the page):</p>
<p><img src="/images/physics4.svg" width="614" height="461" loading="lazy" decoding="async" alt="The inferred bumper configuration and ball trajectory."></p>
<p>Earlier samples from the Markov chain are shown closer to turquoise.
We can see the “<span class="prose-compound">burn-in</span>” process as the initial samples have low
likelihood: they do not land in the cup. The ball begins landing in the
pot after around 100 samples (68, 109, 118, 163 in the above
animations).</p>
<p>The entire distribution will eventually be explored but only
asymptotically. For simplicity we just restarted the simulation to get
the four different animations at the <a href="#top">top of the page</a>,
rather than waiting for one <span class="prose-compound">M-H</span> chain to randomly enter many different
modes.</p>
