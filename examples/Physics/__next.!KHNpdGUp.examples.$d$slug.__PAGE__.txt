1e:Tba22,<span id="top"></span><p>One advantage of probabilistic programming in a general purpose
language is that we can import existing libraries as part of our models.
Here we follow an example from the Anglican team with a simple 2d
physics problem based on the Chipmunk library. For the Anglican example
see the <a href="https://bitbucket.org/probprog/mlss2015/src/master/">Machine
Learning Summer School</a> or <a href="https://github.com/hongseok-yang/probprog19/blob/master/Lectures/Lecture4/PhysicsLec4.clj">the
KAIST lecture course</a>. For more advanced physics simulations in
probabilistic programming, see <a href="https://iris-hep.org/projects/ppx.html">PPX</a>.</p>
<p>Thanks also to <a href="https://github.com/ahuoguo/lazyppl_physics">Alexander Bai</a> for
initially adapting the Haskell implementation in Sam’s <a href="https://www.cs.uoregon.edu/research/summerschool/summer19/topics.php#Staton">OPLSS
course</a> to LazyPPL.</p>
<p>The source for this Literate Haskell file is currently <a href="https://github.com/lazyppl-team/lazyppl_physics">here</a>.</p>

<ul>

<li><p>There is a cup at a fixed position.</p></li>
<li><p>We want to place and orient bumpers so that the ball falls in to
the cup.</p></li>
</ul>

<h2 id="the-lazyppl-model">The LazyPPL model</h2>
<p>The model:</p>
<ul>
<li><p>Pick some bumper positions and angles uniformly</p></li>
<li><p>Run the 2d physics</p></li>
<li><p>Then observe that the ball lands <span class="prose-compound">more-or-less</span> in the
cup.</p></li>
<li><p>Return a posterior distribution over bumper positions and
angles.</p></li>
</ul>
<div class="sourceCode code-block" id="cb9"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb9-1"><a href="#cb9-1" aria-hidden="true" tabindex="-1"></a><span class="ot">model ::</span> <span class="dt">Meas</span> [(<span class="dt">Double</span>,<span class="dt">Double</span>,<span class="dt">Double</span>)]</span>

<span id="cb9-4"><a href="#cb9-4" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- Prior is uninformative, uniformly distributed</span></span>
<span id="cb9-5"><a href="#cb9-5" aria-hidden="true" tabindex="-1"></a>  bumpers <span class="ot">&lt;-</span> sample <span class="op">$</span> replicateM <span class="dv">2</span> <span class="op">$</span> <span class="kw">do</span></span>

<span id="cb9-17"><a href="#cb9-17" aria-hidden="true" tabindex="-1"></a>  <span class="co">-- Return the bumper positions</span></span>

<p>Note that we do not say that the ball lands exactly in the cup. We
could consider an alternative model by replacing the score with
<code>score $ fromEnum (x &gt; 4 &amp;&amp; x &lt; 5)</code>. This would
lead to <span class="prose-compound">Metropolis-Hastings</span> rejecting the first samples, finding the
first success by <a href="#brute-force">brute force</a>, which takes a
lot longer.</p>
