<h2 id="jump">Jump diffusion compositionally</h2>
<p>Recall the splice function <code>splice :: Prob [Double] -&gt; Prob (Double -&gt; Double) -&gt; Prob (Double -&gt; Double)</code> from <a href="/examples/RegressionDemo/#piecewiseLinearRegression">the linear regression example</a>, which pieces together draws from a random function using a point process. We can immediately apply this to the Wiener process, to get a jump diffusion process.</p>
