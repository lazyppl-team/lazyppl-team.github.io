<p>Additive clustering is a method for inferring features over a set of of objects using similarity data. The nature of the features is unknown, and the number of possible features is unknown, and inferred using the Indian Buffet Process. Each feature has an associated “saliency” weight indicating how much it contributes to the similarity coefficient. We also infer the saliency weights.</p>

<h2 id="additive-clustering-model">Additive clustering model</h2>
<p>The Indian Buffet Process provides abstract types <code class="sourceCode haskell"><span class="dt">Restaurant</span></code> and <code class="sourceCode haskell"><span class="dt">Dish</span></code>, and the following interface:</p>
<ul>
<li><p><code class="sourceCode haskell"><span class="ot">newRestaurant ::</span> <span class="dt">Double</span> <span class="ot">-&gt;</span> <span class="dt">Prob</span> <span class="dt">Restaurant</span></code> opens a new restaurant;</p></li>
<li><p><code class="sourceCode haskell"><span class="ot">newCustomer ::</span> <span class="dt">Restaurant</span> <span class="ot">-&gt;</span> <span class="dt">Prob</span> [<span class="dt">Dish</span>]</code> assigns a finite set of dishes to a new customer.</p></li>
</ul>
<p>Our additive clustering models has three parameters (<code>alpha</code>, <code>lambda1</code> and <code>lambda2</code>) and produces a mapping from countries to lists of features. We use an Indian Buffet Process abstraction, so we imagine that each country arrives as a customer at a buffet, and takes some dishes, which are the features. We can then assess which countries took similar dishes to see which countries are similar.</p>
<div class="sourceCode code-block" id="cb11"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb11-1"><a href="#cb11-1" aria-hidden="true" tabindex="-1"></a><span class="ot">additiveClustering ::</span> <span class="dt">Double</span> <span class="ot">-&gt;</span> <span class="dt">Double</span> <span class="ot">-&gt;</span> <span class="dt">Double</span></span>
<span id="cb11-2"><a href="#cb11-2" aria-hidden="true" tabindex="-1"></a>                   <span class="ot">-&gt;</span> <span class="dt">Array</span> (<span class="dt">Country</span>,<span class="dt">Country</span>) <span class="dt">Double</span> <span class="ot">-&gt;</span> <span class="dt">Meas</span> (<span class="dt">Array</span> <span class="dt">Country</span> [<span class="dt">Dish</span>])</span></code></pre></div>

<div class="sourceCode code-block" id="cb12"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb12-1"><a href="#cb12-1" aria-hidden="true" tabindex="-1"></a>additiveClustering alpha lambda1 lambda2 similarityData <span class="ot">=</span> <span class="kw">do</span></span>

<p>Each dish is randomly assigned a weight, which is how important it is to the similarities between countries.</p>
<div class="sourceCode code-block" id="cb13"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb13-1"><a href="#cb13-1" aria-hidden="true" tabindex="-1"></a>    (<span class="ot">weights ::</span> <span class="dt">Dish</span> <span class="ot">-&gt;</span> <span class="dt">Double</span>) <span class="ot">&lt;-</span> sample <span class="op">$</span> memoize (<span class="op">\</span>d <span class="ot">-&gt;</span> gamma lambda1 lambda2)</span></code></pre></div>
<p>Each country is assigned a list of dishes, by regarding it as a new customer in the restaurant.</p>
<div class="sourceCode code-block" id="cb14"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb14-1"><a href="#cb14-1" aria-hidden="true" tabindex="-1"></a>    (<span class="ot">features ::</span> <span class="dt">Array</span> <span class="dt">Country</span> [<span class="dt">Dish</span>])</span>
<span id="cb14-2"><a href="#cb14-2" aria-hidden="true" tabindex="-1"></a>           <span class="ot">&lt;-</span> listArray (<span class="fu">minBound</span>,<span class="fu">maxBound</span>) <span class="op">&lt;$&gt;</span></span>

<span id="cb14-4"><a href="#cb14-4" aria-hidden="true" tabindex="-1"></a>              sample <span class="op">$</span> newCustomer restaurant)</span></code></pre></div>
<p>We define a function that calculates the similarity of two countries given the dishes that they share.</p>
<div class="sourceCode code-block" id="cb15"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb15-1"><a href="#cb15-1" aria-hidden="true" tabindex="-1"></a>    <span class="kw">let</span><span class="ot"> similarity ::</span> <span class="dt">Country</span> <span class="ot">-&gt;</span> <span class="dt">Country</span> <span class="ot">-&gt;</span> <span class="dt">Double</span></span>
<span id="cb15-2"><a href="#cb15-2" aria-hidden="true" tabindex="-1"></a>        similarity i j <span class="ot">=</span> <span class="fu">sum</span> [weights a <span class="op">|</span> a <span class="ot">&lt;-</span> features<span class="op">!</span>j, a <span class="ot">`elem`</span> features<span class="op">!</span>i]</span></code></pre></div>

<div class="sourceCode code-block" id="cb16"><div class="code-copy-control"><span class="code-language">Haskell</span><span class="code-scroll-hint" hidden="">Scroll within code</span><span class="code-copy-mount"></span></div><pre class="sourceCode haskell literate" tabindex="0" role="region" aria-label="Haskell code"><code class="sourceCode haskell"><span id="cb16-1"><a href="#cb16-1" aria-hidden="true" tabindex="-1"></a>    <span class="fu">mapM_</span> (<span class="op">\</span>(i, j) <span class="ot">-&gt;</span> score <span class="op">$</span> normalPdf (similarityData<span class="op">!</span>(i,j)) <span class="fl">0.1</span> (similarity i j)) [ (i, j) <span class="op">|</span> i <span class="ot">&lt;-</span> countries, j <span class="ot">&lt;-</span> countries, j <span class="op">&lt;</span> i ]</span></code></pre></div>
<p>We return the feature assignment.</p>

<h2 id="simulation">Simulation</h2>
<p>We sample from this using Metropolis Hastings simulation, and plot the features of the sample with the highest likelihood. The columns represent the found features, with a coloured box if the country has that feature.</p>
