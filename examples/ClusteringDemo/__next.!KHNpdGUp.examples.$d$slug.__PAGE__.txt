<p>We first define a generic clustering model that uses a Chinese Restaurant process. The parameters for our generic clustering model are:</p>
<ul>
<li><code class="sourceCode haskell"><span class="ot">xs ::</span> [a]</code>, a data set<br>
</li>
<li><code class="sourceCode haskell"><span class="ot">pparam ::</span> <span class="dt">Prob</span> b</code>, from which we sample a parameter for each cluster</li>
<li><code class="sourceCode haskell"><span class="ot">like ::</span> b <span class="ot">-&gt;</span> a <span class="ot">-&gt;</span> <span class="dt">Log</span> <span class="dt">Double</span></code>, parameterized likelihood function, which we use to score the cluster assignment for each data point</li>
</ul>

<p>Here we are using our Chinese Restaurant process interface (<code>Distr.DirichletP</code>). It involves abstract types <code class="sourceCode haskell"><span class="dt">Restaurant</span></code> and <code class="sourceCode haskell"><span class="dt">Table</span></code>, and provides two functions:</p>
<ul>
<li><code class="sourceCode haskell"><span class="ot">newRestaurant ::</span> <span class="dt">Double</span> <span class="ot">-&gt;</span> <span class="dt">Prob</span> <span class="dt">Restaurant</span></code>, which provides a new restaurant;</li>
<li><code class="sourceCode haskell"><span class="ot">newCustomer ::</span> <span class="dt">Restaurant</span> <span class="ot">-&gt;</span> <span class="dt">Prob</span> <span class="dt">Table</span></code>, which says which table a new customer will sit at.</li>
</ul>
<p>We model data points by customers to a restaurant, and they are in the cluster if they sit at the same table. The restaurant is implemented in <code>Distr.DirichletP</code> by a lazy <span class="prose-compound">stick-breaking</span> construction.</p>
<p>The tables support stochastic memoization via a function <code class="sourceCode haskell"><span class="ot">memoize ::</span> (<span class="dt">Table</span> <span class="ot">-&gt;</span> <span class="dt">Prob</span> a) <span class="ot">-&gt;</span> <span class="dt">Prob</span> (<span class="dt">Table</span> <span class="ot">-&gt;</span> a)</code>. This is defined using laziness (lazy tries). This memoization allows us to randomly assign parameters and colours to clusters/tables.</p>
<p>We try clustering on the synthetic data set <code>dataset</code>.</p>
